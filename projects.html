PROJECT 01 · CYBERSECURITY / PYTHON

Suspicious File Detection & Basic Malware Analysis Tool

FEATURED

Objective: Automate scanning of a user-selected local directory to identify files with selected executable or script extensions, calculate SHA-256 fingerprints, compare hashes with a predefined sample blacklist and create a scan report.

How it works

  • Accepts a directory path from the user and validates that it exists.
  • Uses os.walk() to recursively traverse folders.
  • Filters files ending in .exe, .bat, .vbs, .ps1 and .js.
  • Reads files in binary chunks of 4096 bytes and calculates SHA-256 with hashlib.
  • Compares calculated hashes against a predefined Python set of sample signatures.
  • Writes a timestamped scan_report.txt with file paths, hashes and statuses.

Libraries & concepts

  • os: directory traversal and path handling.
  • hashlib: SHA-256 digest generation.
  • datetime: report timestamping.
  • Binary file handling: safe reading of executable content.
  • Set lookup: efficient hash membership checks.
The extension filter identifies files for review, not malware by itself. A file is marked blacklisted only when its hash matches an entry in the configured sample blacklist.
